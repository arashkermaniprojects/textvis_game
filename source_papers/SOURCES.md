are **not** redistributed in this repository because most of them are under
publisher copyright. To regenerate a lecture, obtain the PDF yourself (from
the publisher, your library, or the open-access link where one exists) and
save it here under the file name given in the first column, e.g.
`source_papers/fuzzy_logic_zadeh_1965_information_control.pdf`. The file
name (without `.pdf`) is the lecture's `--basename`.
